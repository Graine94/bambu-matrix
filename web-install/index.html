Bambu Matrix

Bambu Lab print status on a MAX7219 64×8 LED matrix · version __VERSION__

1. Install the firmware

  1. Open this page in Chrome or Edge on a computer (Safari and Firefox can't talk to USB devices).
  2. Connect the ESP32 board to the computer with a USB data cable.
  3. Press the button below and pick the board's port (usually CP210x, CH340 or usbserial).

This browser can't install over USB — open the page in Chrome or Edge on a computer. Installing only works over https — open the page at its regular address.

If the port doesn't show up, install the USB-UART driver for your board (CH340 or CP210x). If flashing doesn't start, hold the BOOT button on the board while plugging it in.

2. Connect to Wi-Fi

  1. After flashing, the matrix scrolls SETUP WIFI: BambuMatrix PASS: bambu123.
  2. On your phone, join the BambuMatrix network, password bambu123. The setup page opens by itself (or go to 192.168.4.1).
  3. “Configure WiFi” → pick your network (2.4 GHz) → password → Save. The printer fields can stay empty.
  4. The matrix connects and scrolls its address, for example IP 192.168.1.53.

3. Pick your printer

  1. Open the address the matrix showed (or http://bambu-matrix.local) on your phone or computer.
  2. Tap your printer in the “Found on the network” list.
  3. Enter the Access Code — it's on the printer screen in the network (WLAN) settings.
  4. Done: the status changes to “Connected”, and the matrix shows progress while printing.

The printer and the matrix must be on the same network. If the printer isn't found, enter its IP manually — it's in the same network settings on the printer.

SETUP: http://…Wi-Fi is fine, no printer selected yet — open this address
ACCESS CODE?the printer rejected the Access Code — check the code
PRINTER … NOT FOUNDnothing answers at this IP — check the IP and that the printer is on
