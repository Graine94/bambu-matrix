# Bambu Matrix

[English](README.md) · **Русский**

Статус печати 3D-принтера Bambu Lab на светодиодной матрице MAX7219 64×8 и ESP32.
Прогресс, оставшееся время, нагрев, пауза, остывание стола, а в простое — часы с погодой.
Всё настраивается в веб-морде с телефона, обновления — по Wi-Fi.

**Установка из браузера:** https://graine94.github.io/bambu-matrix/ (Chrome или Edge на компьютере)

## Что нужно

| | |
|---|---|
| Плата | любая на классическом **ESP32** с 4 МБ flash: ESP32 DevKit, LOLIN32 Lite, WROOM-32 и т.п. (ESP32-S2/S3/C3 не подходят) |
| Матрица | MAX7219, **8 модулей 8×8** подряд (64×8), обычно продаётся как «FC-16 4 в 1» ×2 или «8 в 1» |
| Принтер | Bambu Lab: X1, P1, A1, P2S, H2D — в той же сети, что и матрица |
| Питание | 5 В для матрицы, общая земля с ESP32 |

### Подключение

| MAX7219 | ESP32 |
|---|---|
| VCC | 5 В (VIN / 5V) |
| GND | GND |
| DIN | GPIO23 |
| CLK | GPIO18 |
| CS | GPIO5 |

Если на плате нет вывода 5 В (как у LOLIN32 Lite), запитай матрицу от отдельного USB-блока 5 В,
а GND матрицы соедини с GND платы. На пин 3V3 5 В подавать нельзя.

## Установка

### Из браузера (проще всего)

1. Открой https://graine94.github.io/bambu-matrix/ в Chrome или Edge на компьютере.
2. Подключи ESP32 по USB, нажми «Установить на ESP32», выбери порт.

### Из исходников (PlatformIO)

```bash
pio run -t upload
```

## Первая настройка

1. После прошивки матрица прокручивает `SETUP WIFI: BambuMatrix PASS: bambu123`.
2. С телефона подключись к Wi-Fi **BambuMatrix** (пароль `bambu123`) — откроется страница настройки
   (или зайди на `192.168.4.1`). «Configure WiFi» → своя сеть 2,4 ГГц → пароль → Save.
   Поля принтера можно оставить пустыми.
3. Матрица подключится к сети и прокрутит свой адрес, например `IP 192.168.1.53`.
4. Открой этот адрес (или `http://bambu-matrix.local`). В разделе «Принтер» нажми на свой принтер
   в списке «Найдены в сети» и введи **Access Code** — он на экране принтера в настройках сети (WLAN).

Серийный номер принтера определяется сам. Если какая-то модель его не отдаёт — введи вручную в веб-морде.

## Сообщения на матрице

| Матрица | Что значит |
|---|---|
| `SETUP WIFI: BambuMatrix …` | нет Wi-Fi — подключись к BambuMatrix и настрой сеть |
| `WiFi...` | ищет сохранённую сеть (через 3 минуты без сети снова включит SETUP) |
| `IP 192.168.1.53` | подключилась к Wi-Fi, это адрес веб-морды |
| `SETUP: http://…` | принтер не выбран — открой адрес и выбери принтер |
| `ACCESS CODE?` | принтер не принял Access Code |
| `PRINTER … NOT FOUND` | по этому IP принтер не отвечает (проверь IP и что принтер включён) |
| `OTA` и полоса | обновление прошивки по Wi-Fi |

Если с этими настройками матрица уже хоть раз подключалась, а потом принтер пропал — значит, его выключили:
экран просто гаснет (или показывает часы, если так выбрано).

## Возможности веб-морды

- 7 видов прогресса с превью, демо на матрице
- яркость днём и ночью: по расписанию или от заката до рассвета
- плавное включение; проверка изображения для модулей с другой разводкой и поворот на 180°
- нагрев сопла и стола перед печатью, 3 режима паузы
- после печати: анимация, остывание стола до READY, автоотключение экрана
- в простое: часы, часы с погодой (Open-Meteo, а если он недоступен — MET Norway; без ключа), заставка «дождь»
- значки погоды для дня и ночи: ясно, малооблачно, облачно, туман, морось, дождь, снег, гроза
- автоматический часовой пояс по городу
- поиск принтеров в сети, понятный статус подключения
- интерфейс на английском и русском (переключатель EN / RU)
- проверка обновлений и установка одной кнопкой с GitHub, по запросу

## Обновления

Версия прошивки видна в веб-морде в разделе «Система».

- **С GitHub.** Нажми **«Проверить обновления»** в «Системе». Если есть новый релиз — веб-морда покажет
  версию, описание изменений и кнопку **«Обновить»**:
  матрица сама скачивает прошивку с GitHub, показывает `OTA` и полосу и перезагружается. Все настройки,
  включая Wi-Fi, сохраняются. Прошивка принимается только с GitHub — соединение проверяется
  по корневым сертификатам GitHub (`include/github_ca.h`).
- **Из файла.** «Система» → «Обновить прошивку» → `bambu-matrix-ota.bin` из
  [релиза](https://github.com/Graine94/bambu-matrix/releases).
- **Переустановка через веб-установщик** тоже сохраняет Wi-Fi и настройки, если не отметить в установщике
  «Erase device».
- **Через esptool** — всё одним файлом (стирает Wi-Fi и настройки):
  `esptool --chip esp32 write-flash 0x0 bambu-matrix.bin`
- **Из исходников:** `pio run -e ota -t upload` (по адресу `bambu-matrix.local`).

## Если не работает

- **Принтер не находится в списке** — проверь, что принтер и матрица в одной сети (гостевые сети и
  разные VLAN мешают). Введи IP вручную.
- **`ACCESS CODE?`** — код мог смениться: посмотри актуальный на экране принтера.
- **Подключается, но статуса нет** — на свежих прошивках некоторых моделей для сторонних устройств
  нужно включить на принтере «LAN Only» или «Developer Mode».
- **Принтер P1/A1 и много клиентов** — у этих моделей ограничено число одновременных локальных
  подключений (Bambu Studio, Handy, Home Assistant). Закрой лишние.
- **Картинка зеркальная или «в кашу»** — «Система» → «Изображение выглядит неправильно?»: перебери варианты, пока на матрице не прочитается `ABC 123` слева направо.
- **Не подключается к Wi-Fi** — ESP32 работает только с 2,4 ГГц.
- **При включении горят все светодиоды и не гаснут** — микросхемы MAX7219 запустились раньше ESP32
  и ушли в тестовый режим. Прошивка раз в секунду заново отправляет настройки матрицы, так что это проходит само.
  Если нет — поставь подтяжку 10 кОм с CS на 3,3 В и конденсатор 100–470 мкФ между 5 В и GND матрицы.

## Безопасность

Веб-морда и обновление прошивки доступны без пароля всем в локальной сети. Пароль точки доступа
настройки — `bambu123` (задан в `src/main.cpp`, `AP_PASS`). Не делай матрицу доступной из интернета
(не пробрасывай на неё порты на роутере).

Сама матрица только обращается наружу, и только к этим сервисам:

- `pool.ntp.org`, `time.google.com` — время
- `api.open-meteo.com`, а если он недоступен — `api.met.no` — погода, восход и закат
- `api.github.com`, `github.com` и его хранилище файлов — только когда нажимаешь «Проверить обновления» или «Обновить»

Поиск города в веб-морде (`geocoding-api.open-meteo.com`) идёт из браузера телефона, а не с матрицы.
С принтером матрица общается только в локальной сети, данные о нём в интернет не уходят.

## Как это устроено

ESP32 подключается к принтеру по локальному MQTT (TLS, порт 8883, логин `bblp`, пароль — Access Code)
и подписывается на `device/<серийник>/report`. Отчёты разбираются потоково с фильтром — большие
сообщения не держатся в памяти целиком. Отрисовка матрицы идёт в отдельной задаче на ядре 0,
сеть и логика — на ядре 1. Принтеры в сети находятся по SSDP, как в Bambu Studio.
